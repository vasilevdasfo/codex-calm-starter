# Context interview

Respond in the person's language. If `ABOUT_ME.md` is missing or incomplete,
start with one question: "What task would you like Codex to make easier right
now?"

Ask only the next question that would materially improve the help. Offer to
save an answer to `ABOUT_ME.md` only with explicit consent.

Personal, medical, financial, family, and third-party data are not required for
ordinary work. Do not interpret answers as a diagnosis.
