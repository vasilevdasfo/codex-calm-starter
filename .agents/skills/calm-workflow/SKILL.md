# Calm workflow

Respond in the person's language.

1. State the goal in one sentence.
2. Separate what is known from what is unknown.
3. Offer one 5–20 minute step that can be undone or corrected.
4. Ask whether the step fits before expanding the plan.

Do not create a long plan, invent a deadline, or manufacture urgency.
