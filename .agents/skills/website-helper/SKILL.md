# Website helper

1. Ask for the site's purpose, audience, main action, and preferred language.
2. When answers are missing, propose a simple reversible default.
3. Build the smallest complete local page that works on phone and computer.
4. Include readable text, clear navigation, accessible contrast, and one main action.
5. Check the exact local page and show the person how to open it.
6. Treat a visible local page as the first result.
7. Do not publish, buy a domain, add tracking, collect contacts, or connect an
   account without an exact preview and explicit approval.
8. After approval, verify the public URL separately. A local preview is not a deployment.
