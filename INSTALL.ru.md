# Установка

## Что скачать

- Официальное приложение ChatGPT с разделом Codex:
  <https://chatgpt.com/download/>
- Этот репозиторий: **Code → Download ZIP**.
- Дополнительно ничего устанавливать не требуется.

Используйте собственный аккаунт OpenAI. Не передавайте другому человеку
пароль, коды входа, API-ключи или существующую папку `.codex`.

## Настройка

1. Распакуйте ZIP в удобную локальную папку.
2. В Finder или Explorer сделайте копию `ABOUT_ME.template.md` и переименуйте
   её в `ABOUT_ME.md`.
3. Либо создайте личный файл через терминал:
   `cp ABOUT_ME.template.md ABOUT_ME.md`
4. На Windows PowerShell используйте:
   `Copy-Item ABOUT_ME.template.md ABOUT_ME.md`
5. Откройте папку как локальный проект в Codex.
6. Убедитесь, что Codex видит корневой `AGENTS.md`.
7. Отправьте:

   `Прочитай AGENTS.md и ABOUT_ME.md. Ничего не отправляй и не меняй вне этой папки. Предложи один маленький следующий шаг.`

## Почему навыки уже работают

Проектные навыки находятся в `.agents/skills`. Это официальный
репозиторий-локальный формат Codex. Не нужно копировать их в домашнюю папку и
не нужно заменять глобальные настройки.

## Необязательная проверка безопасности

Если Python 3 уже установлен:

`python3 scripts/validate_starter.py`

Затем попросите Codex показать найденные навыки и объяснить, когда каждый из них
будет использоваться.
