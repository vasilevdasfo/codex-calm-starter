# Установка для человека без технического опыта

## Что нужно

- Официальное приложение ChatGPT с Codex: <https://chatgpt.com/download/>
- Starter: используйте только точную версионную ссылку с одобренной клиентской
  страницы. Не заменяйте её плавающей ссылкой `latest`.
- Собственный аккаунт OpenAI.

Не нужно устанавливать Git, Python, Xcode Command Line Tools или дополнительные
скиллы. Если macOS предлагает установить инструменты разработчика, нажмите
«Отмена»: для обычного запуска Starter они не нужны.

## Что сделать

- Распаковать ZIP.
- В Codex выбрать всю распакованную папку.
- Написать `НАЧАТЬ`.

Дальше Codex задаёт вопросы по одному и объясняет каждый шаг.

## Что не переносить

Не копируйте с другого компьютера `.codex`, `.claude`, чаты, память, браузерные
профили, cookies, токены или сохранённые аккаунты. Почта, календарь, Telegram,
Drive и GitHub подключаются по одному под владельцем нового компьютера.
