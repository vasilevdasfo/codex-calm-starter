# НАЧАТЬ ЗДЕСЬ

Вам не нужно разбираться в программировании, Git или терминале.

## Три действия

- Установите официальное приложение ChatGPT с Codex:
  <https://chatgpt.com/download/>
- Распакуйте Starter и откройте всю распакованную папку в Codex.
- В новом сообщении напишите только:

  `НАЧАТЬ`

Codex сам проверит комплект, задаст несколько коротких необязательных вопросов
по одному и поможет получить первый полезный результат.

## Если что-то не получилось

Снова откройте всю папку Starter в Codex и напишите:

`НАЧАТЬ — ПРОВЕРЬ УСТАНОВКУ`

Вы получите одну понятную причину и одно действие для исправления.

Если macOS предлагает установить «инструменты разработчика», отмените это окно.
Starter должен проверяться внутри Codex без Terminal, Python и системных установок.

Если ответы выглядят слишком поверхностно и внизу окна выбран режим
`5.6 Sol Light`, для серьёзной задачи выберите обычный `5.6 Sol`, если он
доступен. Starter не может переключать модель за владельца.

## Важно

- Используйте свой аккаунт OpenAI.
- Не передавайте никому пароль или код входа.
- Starter не копирует чужие чаты, память или аккаунты.
- Ничего не отправляется на сайт автоматически.
- Публикация сайта, отправка письма и подключение аккаунта требуют отдельного подтверждения.
