# Contributing

Keep the starter small, reversible, and privacy-first.

- Do not add personal examples, real credentials, private messages, account
  identifiers, or machine-specific paths.
- Prefer repository-local instructions and skills.
- Do not add connectors, hooks, remote access, or automatic external actions
  to the default package.
- Update both English and Russian onboarding when behavior changes.
- Run `python3 scripts/validate_starter.py` before opening a pull request.
