# Codex Calm Starter

[English](README.md) · Русский

Спокойный старт Codex для человека без технического опыта. В комплекте нет
чужих чатов, аккаунтов, памяти, ключей или заполненного личного профиля.

**[Скачать текущий публичный релиз](https://github.com/vasilevdasfo/codex-calm-starter/releases/latest)**

## Самый простой старт

- Установите официальное приложение ChatGPT с Codex:
  <https://chatgpt.com/download/>
- Распакуйте Starter и откройте всю папку в Codex.
- Напишите: `НАЧАТЬ`.

Подробная инструкция: `НАЧАТЬ_ЗДЕСЬ.md`.

## Что произойдёт

- понятная локальная проверка установки;
- не больше пяти коротких необязательных вопросов;
- одна полезная задача и один видимый результат;
- понятные нумерованные варианты продолжения.

## Три слоя

- Обязательное ядро: первый запуск, приватность, ProblemOS Lite и навигация.
- Рабочие модули по запросу: сайт, почта и идеи.
- Добровольная поддержка: локальный preview уровня и запроса помощи.

Клиенту не нужно выбирать или устанавливать скиллы вручную. Codex обнаруживает
их в `.agents/skills` после открытия папки.

## Приватность

Личные `ABOUT_ME.md`, `MY_PROGRESS.md`, отчёты и первые результаты игнорируются
Git. Ничего не отправляется автоматически. Подключение аккаунта, отправка
письма и публикация сайта требуют отдельного подтверждения.

## Доверие и проверка

- [Исходный код на GitHub](https://github.com/vasilevdasfo/codex-calm-starter)
- [Публичные релизы](https://github.com/vasilevdasfo/codex-calm-starter/releases)
- Каждый новый ZIP получает SHA-256 checksum для проверки файла.
- Участники проекта указываются только с подтверждённой ролью и согласием.

## Для поддержки

Если Python 3 доступен:

`python3 scripts/validate_starter.py`

Ожидаемый результат начинается с `PASS`.
