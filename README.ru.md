# Codex Calm Starter

[English](README.md) · Русский

Минимальное спокойное рабочее пространство для первого знакомства с Codex.
В репозитории нет чужих чатов, ключей, аккаунтов, задач или личного профиля.

**[Скачать Codex Calm Starter v0.1.0 (ZIP)](https://github.com/vasilevdasfo/codex-calm-starter/releases/download/v0.1.0/codex-calm-starter-v0.1.0.zip)**

## Быстрый старт

1. Скачайте официальное приложение ChatGPT с Codex:
   <https://chatgpt.com/download/>
2. Войдите в собственный аккаунт OpenAI.
3. На GitHub нажмите **Code → Download ZIP** и распакуйте архив.
4. Создайте личный локальный профиль:

   - Без терминала: сделайте копию `ABOUT_ME.template.md` и переименуйте её в
     `ABOUT_ME.md`.
   - macOS/Linux: `cp ABOUT_ME.template.md ABOUT_ME.md`
   - Windows PowerShell: `Copy-Item ABOUT_ME.template.md ABOUT_ME.md`

5. Откройте распакованную папку как локальный проект в Codex.
6. Отправьте первый запрос:

   `Прочитай AGENTS.md и ABOUT_ME.md. Ничего не отправляй и не меняй вне этой папки. Помоги выбрать одну небольшую задачу на сегодня.`

## Что включено

- `AGENTS.md` — спокойные правила, понятные границы и подтверждение перед внешними действиями.
- `ABOUT_ME.template.md` — необязательный опросник о предпочтениях и рабочем ритме.
- `.agents/skills/` — три проектных навыка, которые Codex обнаруживает в этой папке.
- `PRIVACY.md` — правила хранения личного контекста.
- `scripts/validate_starter.py` — локальная проверка структуры и возможных секретов.

## Важное правило приватности

Файл `ABOUT_ME.md` игнорируется Git. Не переименовывайте его и не публикуйте
заполненную версию. Пароли, коды входа, документы, банковские данные и чужую
переписку в этот файл добавлять не нужно.

## Необязательная проверка

Если Python 3 уже установлен, запустите:

`python3 scripts/validate_starter.py`

Ожидаемый результат: `PASS: starter kit is complete and public-safe`.

## Для кого

Для человека без опыта программирования, которому нужен предсказуемый помощник:
одна задача за раз, простой язык, обратимый первый шаг и явное подтверждение
перед отправкой, публикацией, оплатой, удалением или изменением доступа.
