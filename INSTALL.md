# Installation for a non-technical person

## What is needed

- Official ChatGPT desktop app with Codex: <https://chatgpt.com/download/>
- Starter: <https://github.com/vasilevdasfo/codex-calm-starter/releases/latest>
- The new owner's own OpenAI account.

Git, Python, and manual skill installation are not required. Python is used
only for support diagnostics; Codex can inspect the essential files without it.

## What to do

- Extract the ZIP.
- In Codex, select the entire extracted folder.
- Type `START`.

Codex then asks one question at a time and explains every step.

## What not to migrate

Do not copy `.codex`, `.claude`, chats, memory, browser profiles, cookies,
tokens, or saved accounts from another computer. Email, Calendar, Telegram,
Drive, and GitHub are connected one at a time as the new owner.
