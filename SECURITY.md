# Security Policy

## Supported versions

Security fixes target the latest stable release and the current `main` branch.
Pre-releases may change before promotion.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed
credential. Email `dima@vda.vc` with the subject `Codex Calm Starter security`.

Include the affected version or commit, a minimal reproduction, and the impact.
Do not include passwords, tokens, private chats, client data, or other secrets.
You should receive an acknowledgement within 72 hours.

## Scope

This repository is a local starter workspace. It does not provide a hosted
service, remote control, telemetry, automatic sending, or automatic publishing.
Security reports should relate to the tracked source or a published release
asset from this repository.
